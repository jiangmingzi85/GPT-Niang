# 龙娘有嘴版状态表情

本目录提供六张透明 PNG，基于项目现有龙娘立绘及其状态表情，通过内置 ImageGen 调整眼神、眉形并增加对应嘴型。生成日期：2026-10-22。保持白发、紫瞳、龙角、发饰与白紫服饰的原角色风格。

| 文件 | 状态 | 设计 |
| --- | --- | --- |
| `normal.png` | 普通 | 半睁眼、浅笑 |
| `low.png` | 额度偏低 | 担忧神态、下弯嘴 |
| `critical.png` | 额度紧张 | 睁大眼、小幅张嘴 |
| `exhausted.png` | 额度耗尽 | 闭眼、叹气嘴型 |
| `unknown.png` | 读取异常 | 疑惑神态、小波浪嘴 |
| `happy.png` | 开心 / 恢复 | 弯眼、张嘴微笑 |

图片均为 1254×1254，保留透明通道。它们作为可选素材随项目分发，不自动替换角色默认立绘，也不覆盖已有用户绑定。在 Windows 挂件中右键人物，打开“表情与互动设置”，将文件分别导入对应状态即可使用；导入会保存独立副本。

生成约束：保持原角色身份、构图、轮廓、姿态和透明背景，仅调整状态表情及简洁的紫色线条嘴型，不添加文字、道具或背景。生成图可能存在局部细节差异，不保证与原图逐像素一致。
