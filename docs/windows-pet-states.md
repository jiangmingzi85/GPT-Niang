# Windows 状态表情、动作与额度提醒

此扩展适用于 Windows 挂件。macOS 继续使用原有界面及轮询行为。

## 表情与互动

右键人物，选择“表情与互动设置”。为当前角色分别导入普通、额度偏低、额度紧张、额度耗尽、读取异常和开心图片。图片重新编码为本地独立 PNG，原文件不受影响；GIF 只使用第一帧。沿用现有 20 MB、尺寸限制，表情额外限制为 400 万像素。

未配置的状态优先使用普通表情，再回退当前角色的默认立绘。坏图不会换成另一个角色。图片由用户自行提供，不会从单张立绘生成其他表情，也不改变任务栏或快捷方式图标。

“预览”只改变暂时显示，关闭配置窗口后恢复当前额度状态。图片导入和清除绑定立即保存；启用开关、动作选项通过“保存开关与动作设置”保存。清除绑定保留图片文件；角色移除后也保留绑定，便于撤销恢复。

配置面板显示各状态的缩略图及“已配置 / 回退普通表情 / 回退默认立绘”。失效图片优先回退普通表情，再尝试当前角色默认立绘。面板实时解释当前额度状态，以及预览、短暂互动和关闭开关对显示的影响。

表情下降到阈值时立即切换，恢复超过阈值加 2 个百分点后切回，避免临界额度反复切换；耗尽后出现有效正额度立即解除耗尽表情。账户、套餐、角色、窗口重置边界或阈值改变时重新建立基线；异常数据立即显示读取异常并清除旧基线。该表情规则不改变恢复提醒的多采样确认逻辑。

点击人物或确认额度恢复时，可播放轻轻摇摆、轻跳、呼吸缩放三种动作。幅度可调 1–8，持续时间 200–1500 毫秒，默认无额外动作。音乐期间暂停额外动作，仍可切换表情；拖动、菜单、配置窗口或隐藏会取消动作。眨眼、挥手和 Live2D 不在本次范围内。

## 额度预警与恢复

右键人物，选择“额度预警与恢复”。预警默认关闭，开启后监测实际返回的全部有效额度窗口：

| 剩余额度 | 默认状态与提醒 |
| --- | --- |
| 高于 25% | 普通 |
| 不高于 25% | 额度偏低 |
| 不高于 10% | 额度紧张 |
| 0% | 额度耗尽 |

低额度阈值可选 20%、25%、30%，严重不足阈值可选 5%、10%、15%。阈值重启后保留，回升超过阈值加 2 个百分点后重新布防。同一次刷新跨越多档只提醒最严重的一档；多个窗口可在同一气泡中列出。

恢复提醒专指“耗尽后重新可用”。倒计时结束不直接宣布恢复；后续查询有可信重置边界时结合新数据确认，边界不明确时需连续两个采样时间推进的正数样本。一个窗口恢复不代表所有窗口恢复，提示会注明窗口。未知套餐不作恢复推断，但有效的低额度仍可预警。

查询失败、旧缓存、超过 180 秒的数据、未来时间和乱序样本不触发恢复。表情在数据不可用时显示读取异常。第一次有效低额度可提醒一次；关闭后重新开启会建立新基线，不补发旧提醒。

## 后台、声音与提醒协调

“隐藏时继续监测和提醒”默认关闭。开启后，仅在 Windows 挂件进程仍存活时按约一分钟间隔查询；应用退出后停止。不会新增系统服务或启动任务。提醒可能延迟约一个查询周期，边界不明确的恢复确认需要更长时间。

提醒使用原人物气泡，不抢键盘焦点。拖动、菜单、设置、其他气泡或全屏应用期间延后，排队超过十分钟的提醒丢弃。自动语录让位于提醒，不清除尚未显示的回答结束事件。提醒音效默认关闭，开启后沿用松开音效并遵循主声音开关和音量。

本地记录防止正常重启后重复提示。显示前预留确认记录以减少重复打扰，如果此时进程崩溃可能漏掉一次提醒，不承诺异常崩溃下绝对不漏、不重。

## 数据与兼容性

用户数据仍位于原数据目录，未更改额度查询接口及 `status.json` 结构：

- `expressions.json` 和 `expressions/`：角色表情绑定、动作配置及独立图片。
- `quota-alert-settings.json`：界面写入的提醒配置。
- `quota-alert-state.json`：后台写入的状态和待显示事件。
- `quota-alert-ack.json`：界面写入的提醒确认记录。

图片更新同步透明点击区域和着色遮罩，音乐模式下同步刷新图片边界。普通表情切换不保存角色选择，不停止音乐。设置和状态均保存在本机，不上传图片，也不新增依赖。

设计参考：[CodexBar](https://github.com/steipete/CodexBar) 的阈值和恢复状态处理、[VPet](https://github.com/LorisYounger/VPet) 的状态与短暂动作回退机制。本次未复制其运行库或角色素材。

## 验证

Node 测试使用 `npm test`。Windows 测试入口仍为 `npm run test:windows`；新增用例也可单独执行：

```powershell
pwsh -NoProfile -STA -File tests/run-windows-tests.ps1 -ExtensionTest expressions
pwsh -NoProfile -STA -File tests/run-windows-tests.ps1 -ExtensionTest quota-notifications
```

测试使用模拟额度和隔离数据，不需要修改真实账户。测试通过不代替真实桌面的音乐、全屏、多屏和可见性验收。
